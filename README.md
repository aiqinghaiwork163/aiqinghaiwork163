9 年 IT 运维。Homelab、网络、批量部署、自动化。我把基础设施当成产品来做：稳定、可复现、可观测。不是收集工具，是把凌晨三点的故障从仪式收成系统。

---

## 做法

先问物理事实：故障从哪来、谁必须在场、回滚要几分钟。再写脚本、再装进 Docker、再补上观测。能删掉的步骤就删掉。人只处理例外。

专长在把「会做一次」变成「能反复交付」——MDT / WDS / PE 批量装机，AP / AC 与路由交换，NAS 与反向代理，Python / Shell 把重复劳动关掉。

## 系统

**[resource_web](https://github.com/aiqinghaiwork163/resource_web)**  
网盘资源浏览器。聚合检索与管理后台，面向日常找资源的自托管方案。

**[pansou](https://github.com/aiqinghaiwork163/pansou)**  
多网盘聚合搜索界面。对接自建检索 API，轻量、可部署。

**Homelab**  
导航门户、媒体站、库存、消息通道。把家里的小主机集群收成一张能用的产品面——有入口、有版本、有回滚。

日常也会读开源、改开源、把别人的项目接到自己的机架上。仓库在 [repositories](https://github.com/aiqinghaiwork163?tab=repositories)。
